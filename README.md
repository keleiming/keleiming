# YSM Pumps — Open Engineering Data & Tools for Industrial Process Pumps

Welcome to the open technical hub maintained by **YSM Pumps (Jinan Yingsiman Machinery Co., Ltd.)** — an independent foundry and CNC manufacturer of **ANSI/ASME B73.1**, **ISO 5199/2858**, and **API 610** chemical process pumps and aftermarket replacement parts (since 2010, Zibo, Shandong, China).

## Featured Open Repositories

| :--- | :---: | :--- |
